# SelectSGS-Web
Transferring SelectSGS into a web-based platform

**SelectSGS WEB**

**Purpose**

Create a modern web-based configurator, pricing, and quoting platform for SGS Products

**Goals**

    Replace current desktop application
    Improve speed and responsiveness
    Allow browser-based access
    Generate quotes automatically

**Products**

    Condensers - IEC & DTC
    Evaporators - PC, DT/DTX, BTR, STC, CF, FL
    Slab Coils

**Current workflow**

STC Evaporator is selectable from the product-line menu using the same Room Load, # of Evaps, Room Temp, Target TD, capacity tolerance, and face-velocity rules as BTR. It uses Wet ratings above a 25°F target coil temperature and Frosted ratings at or below 25°F; models with no rating for the selected condition are excluded. STC rating data is bundled in `stc-ratings.js`; keep it alongside `unit-selection.html` when hosting the app. Pricing has not been provided, so quote totals and export remain unavailable for STC selections. See [STC Selection Rules](./Documentation/STC_SELECTION_RULES.md).

Serve the project from a local or hosted web server, then open `index.html` to enter project information, including the required sales territory. Once the required details are complete, an eight-row unit list appears; each “Click to Select” button opens `unit-selection.html` for that row, where IEC, DTC, or BTR Evaporator can be selected. IEC and DTC design conditions return qualifying single- or multi-cell solutions, sorted by total list price from lowest to highest. BTR collects Total Room Load (TR), # of Evaps, Room Temp (dF), and Target TD (dF); load and temperatures default to 0.0, Room Temp accepts negative values, # of Evaps defaults to 1 and requires an integer of at least 1, and Target TD must be greater than zero. The dropdowns and calculated values appear after Room Load and Target TD are entered; the default # of Evaps (1) and Room Temp (0.0) count as populated. Dropdowns provide R717, three priced coil materials (SS/AL, AL/AL, and CU/AL), five defrost types, four refrigerant feeds, and an optional HGR-Hot Gas Reheat selection. HGR adds two rows without increasing cooling capacity; it uses the next deeper model for airflow, physical specifications, and pricing, and automatically locks “Add'l Set of Headers for Hot Gas Reheat” into the first selectable option slot. HGR is unavailable on 8-row coils because no 10-row ratings, pricing, or physical specifications are bundled. Calculated values show WET above a 25°F target coil temperature and Frosted otherwise, 630 FPM above a 34°F room temperature and N/A otherwise, target coil temperature as Room Temp minus Target TD, and target capacity per coil as TR × 12,000 ÷ Target TD ÷ # of Evaps (N/A when the default Target TD is zero). After the dropdowns are selected, the BTR results panel shows -15%/+15% capacity difference filters and a Find Units button. Capacity difference is `(rated capacity - target capacity per coil) / target capacity per coil × 100`; DX feed uses DX ratings, while RB, RT, and FL use Recirc ratings. SS/AL and AL/AL use the SS or AL coil ratings tab; CU/AL uses the Steel or CU coil ratings tab. The face-velocity column is calculated from CFM ÷ coil face area; when room temperature is above 34°F, models over 630 FPM are excluded. List Price uses the selected material and defrost type, with HGR models priced from the paired deeper model; the required HGR header option is priced separately on the quote page. Fan HP shows the per-fan rating. Click a BTR result row to select and highlight it, then choose Add to Quote to add its configuration to the quote. FPI and ESP are omitted because the workbook does not provide those values. BTR ratings are bundled in `btr-ratings.js`; keep this file alongside `unit-selection.html` when hosting the app. BTR base and option prices are bundled in `btr-product-pricing.js`; keep this file alongside both HTML pages. IEC selections support R717 and R22; DTC ratings are available for R717 only. DTC ratings are sourced from the DTC tab in the engineering ratings workbook and bundled in `dtc-units.js`. IEC nominal box sizes, rated R717 capacities, and weights are sourced from the IEC tab and bundled in `iec-engineering-data.js`. IEC and DTC base-unit prices and model-specific option prices are bundled in `product-pricing.js`; keep these data files alongside their HTML pages when hosting the app. The quote page keeps project information and the item summary on the left, with selected-unit details above options on the right. Select an item summary row to copy it to the next open line item or delete it; deleting compacts the remaining line items. Up to 12 model-specific options can be selected per unit. The multiplier defaults to 0.35 and applies to the base unit and each selected option; per-cell options are extended across all selected cells. It accepts values greater than 0 through 1. Project, unit, option, and multiplier data are carried between these pages in the current browser tab.

BTR selected-unit details include shipping weight for the selected coil material, from the attached BTR ratings workbook, and overall length x width x height from the BTR dimensional drawings; dimensions are displayed in inches. Keep `btr-ratings.js` alongside both HTML pages because the quote page uses its bundled physical specifications. BTR options and defrost-specific base prices are bundled in `btr-product-pricing.js`; keep it alongside `index.html`. Pricing maps AL/AL to BTRA, SS/AL to BTRB, and CU/AL to BTRC. Steel is omitted until pricing is available.

On the quote page, BTR unit specifications use a two-column equipment layout. BTR options are grouped into Drain Pan, Selectable, and Write-In sections; write-ins support three per-unit lines and their net prices use the project cost multiplier.

BTR specifications now include fan diameter/RPM by series, 0-inch ESP, 4 FPI, workbook coil surface area and airflow, and an air-unit model number formatted from tube, material, model series/rows, feed, refrigerant, and defrost codes. All BTR options use per-unit UOM; the options panel has one drain-pan selector (standard SS-insulated cover is the $0 default except for WD, which defaults to no cover at $0; fully welded hygienic SS cover is priced), six selectable option rows, and three write-in rows. Standard SS-insulated covers are included in the base price for all defrost types except WD. The previous note above that ESP/FPI were omitted is outdated.

Choose **Export Quote** in the Item Summary to download an `.xlsx` workbook populated from the bundled `quote-template.xlsx` attached to this project, with pricing on **Quote Page 0** and a separate condenser detail tab named **Item #_** for each selected item. Each unit's first pricing row keeps the template's merged description cell and lists **Line Item #**, **Location**, and **Model #** in that order, followed by its selected options; two blank rows separate units. The attached workbook is always used; keep `quote-template.xlsx` alongside `index.html` when hosting the app. The evaporator **Item E** tab is not included yet. IEC/DTC base and option prices from `product-pricing.js` and BTR base and option prices from `btr-product-pricing.js` are multiplied by the project cost multiplier before they appear in the quote.

Use **Add to project Tree** on the Project Information page to save the current project in the browser's Project Tree. The tree keeps multiple project and quote snapshots in browser storage; select any entry to switch projects. Changes to the selected project are saved automatically, and **New Project** starts another project without replacing the selected one. Use the single set of Up/Down, Archive/Restore, and Delete controls beneath **New Project** to manage the selected project; archived projects are available from the archived-projects list.
