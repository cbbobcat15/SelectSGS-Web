 # IEC Selection Rules
**Inputs**
1. Capacity Requirements
2. Condensing Temperature
3. Wet Bulb Temperature
4. Refrigerant
5. Motor Voltage

**Selection Process**
1. User Enters Design information
2. System calculates Correction factor based on DB and WB
3. User Defines max number of cells
4. User Defines percent above and below target capacity for results
5. System identifies all qualifying IEC models
6. System initally sorts by price
7. System shows capacity as a percent +/- based on calculated capcity vs design capacity

**Outputs**
1. Model Number 
2. Capacity
3. Total Fan HP
4. Dimensions
5. Price
